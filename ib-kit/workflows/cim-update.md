# CIM and Materials Update Workflow

**Layer:** Execution  ·  **System:** Client Delivery  ·  **Typical duration:** 1–2 weeks per cycle

## When to run

Process materials must be refreshed for a new period, a new audience or after a change in the business.

## Inputs required

- The current materials and their source data
- Updated financials and operating metrics
- Any change in the business, the market or the process

## Phases

### Phase 1 — Assess  *(1–2 days)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Identify every figure affected by the new period or the change | `source-verification-agent` |
| 1.2 | Assess whether the equity story still holds or needs restating | `equity-story-agent` |

### Phase 2 — Update  *(3–5 days)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Refresh the financial section with the new period and restated adjustments | `financial-section-agent` |
| 2.2 | Refresh market data and check whether any market claim has been overtaken | `market-intelligence-agent` |
| 2.3 | Update the growth plan for initiatives that have advanced or stalled | `growth-plan-agent` |

### Phase 3 — Review  *(2–3 days)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Test every claim against what diligence will now reveal | `disclosure-review-agent` |
| 3.2 | Reconcile updated figures against every other live document | `source-verification-agent` |
| 3.3 | Check definitional consistency across all materials | `disclosure-review-agent` |

### Phase 4 — Release  *(1 day)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Confirm disclosure clearance for the new figures | `disclosure-review-agent` |
| 4.2 | Log the version and release it with the changes noted | `process-communication-agent` |

## Gates

- **Consistency gate** — Updated figures reconcile against every other document already in the market.
- **Claim gate** — Any claim overtaken by events is removed, not softened.
- **Version gate** — Every release is versioned and logged; no untracked versions circulate.

## Definition of done

- [ ] All figures updated and reconciled across every live document
- [ ] Claims retested against current diligence material
- [ ] Version logged and disclosure cleared

## Common failure modes

- An updated CIM that contradicts a figure already given to a bidder
- A market claim that was true at launch and is no longer
- Multiple versions circulating with nobody sure which is current
