# Deal Screening Workflow

**Layer:** Execution  ·  **System:** Origination  ·  **Typical duration:** 3–5 weeks

## When to run

A client has acquisition capital and a strategy but no prioritised target list, or a sector needs systematic screening for an origination programme.

## Inputs required

- The client's strategy, criteria and balance sheet capacity
- Sector definition and geographic scope
- Any existing pipeline or prior screening work

## Phases

### Phase 1 — Frame  *(3–5 days)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Establish the client's criteria, weights and affordability envelope before looking at any company | `screening-and-targeting` |
| 1.2 | Define the sector boundary and the adjacencies in scope | `market-intelligence-agent` |
| 1.3 | Agree the screening criteria and weights in writing with the client | `screening-and-targeting` |

### Phase 2 — Build the universe  *(1 week)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Construct the universe from classification, value chain and adjacency rings | `screening-and-targeting` |
| 2.2 | Add sponsor-owned inventory, succession situations and carve-out candidates | `screening-and-targeting` |
| 2.3 | Profile each candidate at one-page depth | `company-research-agent` |

### Phase 3 — Score and tier  *(1 week)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Apply the weighted scorecard and run the weight sensitivity | `screening-and-targeting` |
| 3.2 | Score deliverability separately from desirability | `screening-and-targeting` |
| 3.3 | Assess antitrust and regulatory posture for the priority names | `antitrust-screening-agent` |

### Phase 4 — Quick-cut the priorities  *(1 week)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Build indicative valuations for Tier 1 targets | `valuation-agent` |
| 4.2 | Run the accretion pre-screen and the affordability test | `merger-model-agent` |
| 4.3 | Map competitive tension and estimate what others would pay | `ability-to-pay-agent` |

### Phase 5 — Recommend  *(3–5 days)*

| # | Action | Agent |
|---|---|---|
| 5.1 | Write the screening memo with the Tier 1 list and three recommended approaches | `investment-memo-agent` |
| 5.2 | Design the approach strategy for each recommended target | `screening-and-targeting` |
| 5.3 | Set up trigger-event monitoring for Tier 2 | `pipeline-management-agent` |

## Gates

- **Criteria gate** — Criteria and weights signed off before scoring begins — never after.
- **Deliverability gate** — No target reaches Tier 1 on strategic fit alone; deliverability is scored independently.
- **Affordability gate** — Every Tier 1 target sits inside the client's stated funding envelope.

## Definition of done

- [ ] Universe documented with exclusions and their reasons
- [ ] Scorecard published with weights and weight sensitivity
- [ ] Tier 1 list with one-page profiles and indicative valuations
- [ ] Approach strategy for each recommended target
- [ ] Anti-target list recorded so names do not recirculate

## Common failure modes

- Criteria reverse-engineered around a target someone already favoured
- Screening on desirability only, producing a list of unavailable assets
- Stale financials taken from a vendor database without checking the filing date
