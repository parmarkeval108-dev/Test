# Unsolicited Bid Response Workflow

**Layer:** Execution  ·  **System:** Client Delivery  ·  **Typical duration:** 4–16 weeks

## When to run

An unsolicited approach has been received or is anticipated.

## Inputs required

- The approach terms and the bidder's profile
- Standalone plan and its value
- Register composition and the applicable takeover regime

## Phases

### Phase 1 — Assess  *(1–2 weeks)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Value the company standalone and identify what the bid pays for beyond it | `hostile-bid-agent` |
| 1.2 | Assess the bidder's financing ability, track record and likely maximum | `ability-to-pay-agent` |
| 1.3 | Analyse the register and the vote arithmetic under the applicable regime | `hostile-bid-agent` |

### Phase 2 — Options  *(2–3 weeks)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Compare standalone acceleration, white knight, restructuring and recommending the bid | `hostile-bid-agent` |
| 2.2 | Quantify the standalone case rather than asserting it | `valuation-gap-agent` |
| 2.3 | Identify credible alternative bidders | `buyer-universe-agent` |

### Phase 3 — Respond  *(2–8 weeks)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Prepare the defence document with the standalone case quantified | `hostile-bid-agent` |
| 3.2 | Engage shareholders with the message for each category | `activist-defence-agent` |
| 3.3 | Negotiate where negotiation serves shareholders better than resistance | `negotiation-strategy-agent` |

### Phase 4 — Resolve  *(2–6 weeks)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Advise the board honestly on whether the price should be accepted | `board-materials-agent` |

## Gates

- **Standalone gate** — The standalone case is quantified before any defence is mounted on it.
- **Fiduciary gate** — The board's duty is to shareholders, and the advice reflects that even when it is unwelcome.
- **Timetable gate** — Every action is planned against the regime's mandatory timetable.

## Definition of done

- [ ] Standalone value quantified and defensible
- [ ] Bidder capacity and maximum assessed
- [ ] Alternatives compared on value to shareholders
- [ ] Board advised honestly on the price

## Common failure modes

- Defending on a standalone plan the board has never previously committed to
- Missing a regime deadline because the timetable was not mapped on day one
- Telling the board what it wants to hear about the price
