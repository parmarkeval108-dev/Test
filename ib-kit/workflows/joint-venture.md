# Joint Venture Workflow

**Layer:** Execution  ·  **System:** Execution  ·  **Typical duration:** 3–9 months

## When to run

Two parties want a combination short of an acquisition.

## Inputs required

- Each party's proposed contribution
- The venture's business plan
- Each party's strategic objectives and time horizon

## Phases

### Phase 1 — Value the contributions  *(4–6 weeks)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Value each contribution on a consistent basis | `joint-venture-agent` |
| 1.2 | Derive the ownership split and test it against contribution analysis | `merger-model-agent` |

### Phase 2 — Design governance  *(4–8 weeks)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Design board composition, reserved matters and deadlock resolution | `joint-venture-agent` |
| 2.2 | Define the economics: funding, transfer pricing, distribution policy | `joint-venture-agent` |
| 2.3 | Design the exit: lock-up, transfer rights, put and call, valuation mechanism | `joint-venture-agent` |

### Phase 3 — Test  *(2–3 weeks)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Assess where the parties' interests diverge over time | `joint-venture-agent` |
| 3.2 | Test the structure against one party wanting out early | `joint-venture-agent` |

### Phase 4 — Execute  *(2–4 months)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Negotiate documentation and approvals | `negotiation-strategy-agent` |
| 4.2 | Plan the venture's standing-up including people and systems | `integration-planning-agent` |

## Gates

- **Divergence gate** — The structure is tested against the point at which the parties' interests diverge.
- **Exit gate** — No joint venture is signed without a working exit mechanism and valuation method.
- **Deadlock gate** — Deadlock resolution is designed before it is needed, not negotiated during it.

## Definition of done

- [ ] Contributions valued consistently and the split justified
- [ ] Governance including deadlock resolution agreed
- [ ] Exit mechanics and valuation method documented
- [ ] Early-exit scenario tested

## Common failure modes

- Fifty-fifty ownership with no deadlock mechanism
- An exit valuation method that neither party would accept in practice
- Governance designed for the honeymoon rather than the divergence
