# Sale Process Management Workflow

**Layer:** Execution  ·  **System:** Execution  ·  **Typical duration:** 4–6 months

## When to run

A sell-side mandate is live and must be run from launch to signing.

## Inputs required

- Approved buyer list and process design
- Cleared teaser, CIM and process materials
- Seller decision-making structure and availability

## Phases

### Phase 1 — Launch  *(2–3 weeks)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Execute wave one outreach against the approach plan | `buyer-outreach-agent` |
| 1.2 | Negotiate NDAs and release the CIM on the agreed schedule | `process-communication-agent` |
| 1.3 | Track engagement and diagnose non-responses | `deal-tracking-agent` |

### Phase 2 — First round  *(4–6 weeks)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Manage the question process so answers release consistently | `process-communication-agent` |
| 2.2 | Issue the first-round process letter with evaluation criteria | `process-communication-agent` |
| 2.3 | Evaluate bids on net expected proceeds, not headline | `bid-evaluation-agent` |
| 2.4 | Recommend who advances and who is pushed, and on what | `bid-evaluation-agent` |

### Phase 3 — Second round  *(6–8 weeks)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Run management presentations after rehearsal | `management-presentation-agent` |
| 3.2 | Open the full data room and manage diligence flow | `data-room-navigation-agent` |
| 3.3 | Build the negotiation strategy for each remaining bidder | `negotiation-strategy-agent` |
| 3.4 | Maintain tension and act when credible bidders fall below the threshold | `process-design-agent` |

### Phase 4 — Final and exclusivity  *(3–5 weeks)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Evaluate final bids including markups of the agreement | `bid-evaluation-agent` |
| 4.2 | Defend against re-trade attempts with a quantified response | `negotiation-strategy-agent` |
| 4.3 | Negotiate exclusivity terms with the shortest defensible period | `negotiation-strategy-agent` |

### Phase 5 — Signing  *(2–4 weeks)*

| # | Action | Agent |
|---|---|---|
| 5.1 | Negotiate the agreement with the ask-and-concede map prepared | `negotiation-strategy-agent` |
| 5.2 | Track conditions and the path to closing | `conditions-precedent-agent` |
| 5.3 | Run the post-process review while it is fresh | `post-investment-review-agent` |

## Gates

- **Tension gate** — If credible second-round bidders fall below the agreed minimum, the tension plan is executed before proceeding.
- **Exclusivity gate** — No exclusivity is granted without a defined period, break rights and the diligence scope fixed.
- **Re-trade gate** — Every re-trade attempt is assessed on merit and answered with a quantified position, never split down the middle.

## Definition of done

- [ ] Every contacted buyer's status documented with the reason for any drop-out
- [ ] Bids compared on certainty-adjusted value throughout
- [ ] Agreement signed with conditions and timetable tracked
- [ ] Post-process review completed and circulated

## Common failure modes

- Granting exclusivity too early and losing the only leverage the seller had
- Ranking bids on headline price when structures differ materially
- Letting a buyer's diligence questions reveal a problem to the other bidders
