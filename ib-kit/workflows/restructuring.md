# Restructuring Workflow

**Layer:** Execution  ·  **System:** Execution  ·  **Typical duration:** 3–12 months

## When to run

A business cannot service its capital structure and the options must be assessed and executed.

## Inputs required

- Full capital structure with security, guarantees and intercreditor terms
- Business plan and near-term liquidity position
- Creditor composition and their holdings

## Phases

### Phase 1 — Stabilise  *(2–4 weeks)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Build the 13-week direct cash flow and identify the funding date | `cash-flow-forecasting-agent` |
| 1.2 | Assess immediate liquidity options and any standstill required | `restructuring-analysis-agent` |
| 1.3 | Map the capital structure by entity with security and ranking | `restructuring-analysis-agent` |

### Phase 2 — Analyse  *(4–8 weeks)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Value the business on going-concern and liquidation bases | `restructuring-analysis-agent` |
| 2.2 | Identify the fulcrum security and recoveries above and below it | `creditor-recovery-agent` |
| 2.3 | Test recoveries across a value range, not at a point estimate | `creditor-recovery-agent` |
| 2.4 | Establish who controls the outcome and what they want | `restructuring-analysis-agent` |

### Phase 3 — Options  *(4–6 weeks)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Compare amendment, new money, debt-for-equity, sale and formal process by class | `restructuring-analysis-agent` |
| 3.2 | Model the restructured capital structure and whether it is sustainable | `capital-structure-agent` |
| 3.3 | Build the business plan the new structure must support | `operating-model-agent` |

### Phase 4 — Execute  *(2–9 months)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Negotiate with the classes that control the outcome | `negotiation-strategy-agent` |
| 4.2 | Track conditions, consents and the implementation mechanism | `conditions-precedent-agent` |

## Gates

- **Liquidity gate** — The funding date is known and monitored weekly; everything else is subordinate to it.
- **Fulcrum gate** — No negotiating position is taken before the fulcrum is identified and tested across a value range.
- **Sustainability gate** — The restructured structure must be serviceable in the downside, or it is a deferral not a solution.

## Definition of done

- [ ] Liquidity secured through the process
- [ ] Fulcrum identified with recoveries tested across a value range
- [ ] Option comparison completed by class
- [ ] Restructured structure sustainable in the downside case

## Common failure modes

- Negotiating before knowing where value breaks
- A restructuring that leaves the business still over-levered for its cash flow
- Running out of cash during a negotiation that was going well
