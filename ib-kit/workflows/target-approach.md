# Target Approach Workflow

**Layer:** Execution  ·  **System:** Origination  ·  **Typical duration:** 2–8 weeks

## When to run

A screened target must be approached without a process, on a bilateral basis.

## Inputs required

- The target profile and the strategic rationale
- Ownership and decision-rights map
- Relationship map between the client and the target

## Phases

### Phase 1 — Prepare  *(1 week)*

| # | Action | Agent |
|---|---|---|
| 1.1 | Establish who actually controls a sale decision | `ownership-structure-agent` |
| 1.2 | Research prior process history and why any previous attempt failed | `corporate-history-agent` |
| 1.3 | Build the indicative value and the client's walk-away | `valuation-agent` |

### Phase 2 — Position  *(3–5 days)*

| # | Action | Agent |
|---|---|---|
| 2.1 | Write the rationale as the target's owner would hear it, not as the buyer sees it | `buyer-outreach-agent` |
| 2.2 | Identify the warmest credible route to the decision-maker | `buyer-outreach-agent` |
| 2.3 | Prepare the response to a rebuff and the timeline for a second attempt | `buyer-outreach-agent` |

### Phase 3 — Approach  *(2–6 weeks)*

| # | Action | Agent |
|---|---|---|
| 3.1 | Make the approach and record what was said and by whom | `deal-tracking-agent` |
| 3.2 | Assess the response and what it reveals about willingness and price | `negotiation-strategy-agent` |

### Phase 4 — Convert  *(2–4 weeks)*

| # | Action | Agent |
|---|---|---|
| 4.1 | Move to an indicative proposal with a defensible range | `valuation-agent` |
| 4.2 | Design the bilateral process to protect against a later auction | `process-design-agent` |

## Gates

- **Control gate** — No approach is made before it is established who can actually approve a sale.
- **Walk-away gate** — The client's walk-away price is written down before the first conversation.
- **Auction gate** — The bilateral structure anticipates the seller running a process later, and prices that risk.

## Definition of done

- [ ] Decision-maker identified and approached through the warmest credible route
- [ ] Response assessed and next step defined with a date
- [ ] Indicative range and walk-away documented

## Common failure modes

- A well-screened target lost to a poorly judged first approach
- Approaching a manager who cannot decide, alerting a shareholder who can
- No walk-away price, so the client discovers it during the negotiation
